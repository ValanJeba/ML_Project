# Atmospheric Data Scientist – Predictive Analytics & Weather Trend Modeling

A machine learning project to predict weather conditions such as temperature, humidity, wind speed, and precipitation using historical meteorological data. Implemented with Python and popular ML libraries.

---

## Project Overview

This repository contains code and resources for building, training, and evaluating machine learning models to forecast weather patterns. The project focuses on:

- Data collection and preprocessing  
- Feature engineering and selection  
- Model training and evaluation  
- Visualization of results  

---

## Features

- Supports regression models like Linear Regression, Random Forest, and XGBoost  
- Handles missing data and outlier detection  
- Model performance evaluation using MAE, RMSE, and R² score  
- Clean and modular Python scripts for easy customization  

---

## Tech Stack

- Python 3.xxx  
- Pandas, NumPy  
- Scikit-learn  
- logistic regression
- Matplotlib, Seaborn
- streamlit
- joblib
